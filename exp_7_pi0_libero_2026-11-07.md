# Experiment: Adaptive-step DSRL on π0 / LIBERO-Long
Status: Sweep complete (2026-11-08); fixed k>0 and adaptive underperform — investigating before analysis

## Goal
Test whether steering a generalist flow-matching VLA (π0) at a later integration step k, or choosing k adaptively per chunk, beats standard DSRL (k=0) on the hardest LIBERO suite.

## Decisions (user, 2026-11-07)
- Base policy: π0 only (public LIBERO fine-tuned checkpoint from openpi), as in `dsrl_pi0/`.
- Tasks: 3–5 LIBERO-Long (LIBERO-10) tasks where base π0 is weakest; measure base success on all 10 first.
- Conditions (1 seed each): base policy, DSRL k=0, fixed k at 2–3 values, adaptive k (hybrid SAC, ρ=0.5).
- Framework: port re-noise steering + the adaptive-k actor into the DSRL-π0 JAX code (jaxrl2); keep its training loop.
- Replaces the furniture sweep (exp_6, cancelled 2026-11-07).

- **Checkpoint:** `s3://openpi-assets/checkpoints/pi0_libero` cached under `OPENPI_DATA_HOME=/n/netscratch/olveczky_lab/Lab/charleszhang/openpi_cache`.
- **Code:** `adsrl_pi0/` (sampler, env, rollout, buffer, agent), `train_adsrl_pi0.py`, `scripts/pi0/`, tests `tests/test_pi0_{sampler,agent}.py`.
- **Steering math (openpi flow matching).** t=1 noise, t=0 data, x_t = t·eps + (1−t)·a, network predicts v = eps − a. Euler, N=10, dt=−1/N, t_j = 1 + j·dt (accumulated as in openpi). From one velocity eval at step j: a_hat_j = x_j − t_j·v_j, eps_hat_j = x_j + (1−t_j)·v_j. Steering at k: k=0 → x_0 = w (standard DSRL); k>0 → x_k = t_k·w + (1−t_k)·a_hat_{k−1}, then plain Euler to t=0. Since the Euler step equals t_{j+1}·eps_hat_j + (1−t_{j+1})·a_hat_j exactly, w = eps_hat_{k−1} reproduces the unsteered sample. k ∈ {0..9}; per-sample k via `jnp.where` inside openpi's `while_loop`.
- **Noise layout:** as in DSRL-pi0, the agent's w is one 32-d row tiled over the 50-step horizon, bounded by tanh to [−1, 1] (action_magnitude 1). x_T (noise for steps < k) uses the same layout: x_T ~ N(0, I_32), tiled, appended to the obs as a 32-d key `x_T` (dropped for fixed k=0, so k=0 is exactly DSRL-pi0's network inputs).
- **Agents:** fixed k = DSRL-pi0's `PixelSACLearner` unchanged (critic Q(s, x_T, w)). Adaptive = `HybridPixelSACLearner`: categorical π(k|s,x_T) + one tanh-Gaussian head per k on a shared trunk, critic Q(s, x_T, onehot(k), w), exact-sum actor loss, α_w (target −16 = DSRL 'auto') and α_k (target ρ·log K'), no entropy in the backup (as DSRL-pi0).
- **Episode protocol:** benchmark init states, 10 no-op settle steps (openpi eval), max 520 steps, pi0 queried every 20 steps (DSRL-pi0 query_freq). Rewards: −1 per chunk, 0 + mask 0 on success. Discount 0.999^20 per chunk.
- **Sweep settings (user-approved 2026-11-07):** tasks 8, 4, 6; per task DSRL k=0, fixed k ∈ {3, 6, 8}, adaptive ρ=0.5 (15 runs, seed 0); w = DSRL-pi0's tiled 32-d row, x_T = full 50×32 Gaussian in the obs for k>0 (`--steer.xt_layout full`); 1M env steps per run; eval every 50k env steps: stochastic eval, 50 episodes (main metric, as DSRL-pi0) + deterministic eval (argmax k, mean w), exactly one episode per init state (50), both rows in eval_summary.csv (`mode` = stoch/det). Each eval uses its own RNGs fixed by (seed, eval index, mode), so evals never change the training RNG streams. Resume fails loudly if the agent checkpoint is missing or not at state.pkl's grad step. kempner_h100, 1 run/GPU (16 CPUs, 12 envs, 64 GB), walltime 5:15 (expected ≈3.4 h), ≤13 concurrent jobs (2 x6_* jobs hold the other kempner GPUs), extra runs chained with afterany. Launcher: `scripts/pi0/sweep_exp7.sh`.
- **DSRL-pi0 hyperparameters kept:** batch 256, UTD 20 per chunk, start_online_updates 500, 64×64 pixels + 8-d state, small CNN encoder, hidden (128,128,128), 10 Qs (mean), actor lr 1e-4, critic/temp lr 3e-4, color jitter + crop.

## Analysis
- The pipeline works end to end on GPU: steered sampling (k=0 equals openpi exactly at batch 1), fixed-k and adaptive agents, x_T augmentation, CSV/wandb logging (success, k histogram, |a−a_base|), checkpoint + resume (tested by wall-limit exit and resubmission).
- **Main surprise: DSRL-pi0's noise parameterization is badly out of distribution for pi0 on LIBERO-10.** A single 32-d noise row tiled over the 50-step horizon drops base success from 0.87 to 0.15 on average; injecting such noise even at k=9 (t=0.1) costs 16 points on task 0. Re-noising with a full Gaussian at k=5/8 keeps base performance (0.94 vs 0.96), so the steering mechanism itself is sound.
- Consequence: DSRL k=0 (as in DSRL-pi0) learns relative to its own collapsed start (task 4: 0.12 → 0.59 stoch / 0.52 det at 400k), but did not beat plain pi0 (0.72) within 400k steps. Any comparison of k against the true base policy needs this caveat, or a different w parameterization.
- Adaptive k uses all 10 steps (ρ=0.5 keeps π(k) broad) and tracked or exceeded k=0 early (0.22–0.54 vs 0.08–0.20 before 110k), then both were in the 0.4–0.8 band; 50-episode stochastic evals are too noisy (SE ≈ 0.07) to separate them.
- Throughput is GPU-light: one run per GPU is best; collection (sim + pi0) and updates split time roughly evenly.
