# Experiment: exp8 structured noise layout for DSRL k=0 on pi0 / LIBERO-10
Status: Completed (6 structured runs and 3 tiled + x_T-obs control runs finished 2026-11-08; Results section never written, see the progress log)

## Goal
Test whether making DSRL's noise input in-distribution (structured layout) instead of repeating one 32-d vector over
the 50-step horizon helps standard k=0 DSRL on pi0/LIBERO.

## Setup
- **Layout** (`--steer.w_layout structured`, default `tiled` = exp7 behaviour). With u = (1,...,1)/sqrt(50), pi0 gets
  `w = u z^T + (I - u u^T) x_T`: the observed x_T (50x32) with each channel's time-mean replaced by z_c/sqrt(50).
  Implemented as `adsrl_pi0.rollout.structured_noise(x_T, z)`, applied in `run_episodes` before every pi0 call
  (training collection, stoch and det eval, --eval_only). The critic and actor never decode z (Q(s, x_T, z) works on
  z directly), and pi0 has no noise-critic distillation, so the rollout is the only decode point.
  - z ~ N(0,I) independent of x_T gives w iid N(0,I) (so the random-z warmup is plain pi0); z = sqrt(50)·mean_t x_T
    gives w = x_T.
  - Uses the observed x_T, so the action is deterministic given (s, x_T, z). **Unlike exp7 k=0, x_T (1600-d) is now in
    the agent obs** (`use_xt_obs: true`), as in exp7's k>0 runs. Without it the critic would not be Markov.
  - k>0 and adaptive: the same formula is applied (that was simpler than raising). Needs `--steer.xt_layout full`
    (enforced at parse time and in run_episodes).
- **Bound**: `--action_magnitude b` -> jaxrl2 `LearnedStdTanhNormalPolicy(low=-b, high=b)`, i.e. z = b·tanh(u)
  (tested). Under structured, one unit of z moves each channel's time-mean by 1/sqrt(50) ≈ 0.14, about 7x less than
  tiled (where z is the time-mean). b=1.0 is DSRL's LIBERO value (= exp7), b=2.5 DSRL's real-robot value. The tanh
  log-det adds 32·log b to the entropy; target entropy stays 'auto' (-16) as in exp7.
- **Runs**: tasks 8, 4, 6 x b in {1.0, 2.5}; fixed k=0, xt_layout full, seed 0, 1M env steps, 12 envs; stoch eval
  (50 episodes) + det eval (one per init state) every 50k env steps. All other hyperparameters as exp7
  `pi0_t{4,6,8}_k0_xtfull_s0` (run_info.json checked: batch 256, discount 0.999, multi_grad_step 20,
  start_online_updates 500, hidden [128], actor_lr 1e-4, critic_lr 3e-4, temp_lr 3e-4, num_qs 10, target_entropy auto,
  query_freq 20, resize 64). Run names `pi0_t{t}_k0_xtfull_wstruct_s0` (b=1) and `pi0_t{t}_k0_xtfull_wstruct_b2.5_s0`.
- Hardware: 1 H100 per run (kempner_h100, kempner_pehlevan_lab), 16 CPUs, 64G, walltime 6h (`--max_wall_hours 5.6`,
  resumes from checkpoint if resubmitted). exp7 k=0 took 2.8-3.5 h; k=3 (also with the 1600-d obs) up to 3.75 h.
