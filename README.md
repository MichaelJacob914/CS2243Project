# Adaptive-step DSRL

DSRL steers a frozen diffusion (or flow) policy by letting an RL agent choose the initial noise. This code
generalizes it: the agent injects its noise at denoising step k (k=0 is standard DSRL), either at a fixed k or
at a k it chooses per action chunk (adaptive k). Results so far are in the report page
(`report/index.html`) and in the experiment logs `exp_<n>_<date>.md`.

## Layout

| Path | What it is |
|---|---|
| `adsrl/` | torch code for robomimic (can, square, transport) and FurnitureBench: steered DDIM sampler, base-policy wrapper, x_T obs wrapper, SAC agents (fixed k, adaptive k, uniform-random k, residual SAC) |
| `train_adsrl.py`, `cfg/adsrl/*.yaml` | robomimic/furniture training entry point (Hydra), one config per task |
| `adsrl_pi0/` | JAX code for π0 / π0.5 on LIBERO: steered flow sampler, agents, buffer |
| `train_adsrl_pi0.py` | LIBERO training entry point (`--model pi0` or `--model pi05`) |
| `scripts/` | evals, analyses and plotting; `scripts/slurm/` holds the SLURM scripts behind each experiment |
| `scripts/pi0/`, `scripts/exp14/`, `scripts/furniture/` | π0 LIBERO tools, the critical-windows study, FurnitureBench setup |
| `tests/` | pytest suite (sampler equivalences, agents, buffers, noise scaling) |
| `results/` | small summaries only (json/csv/npy under 1 MB); large arrays stay on the cluster |
| `report/` | report page; figures are regenerated by the plotting scripts (see `report/README.md`) |
| `exp_<n>_<date>.md` | one living document per experiment: setup, SLURM job IDs, progress, results, analysis |
| `notes/` | the original plan, literature review, figure plan |
| `dsrl/`, `dsrl_pi0/` | upstream DSRL repos as git submodules (unmodified) |
| `third_party/stable-baselines3-py38/` | `dsrl/stable-baselines3` with a mechanical Python 3.8 patch, used only for FurnitureBench (see its `PY38_PATCH.txt`) |

## Setup

```bash
git submodule update --init --recursive
```

There are four uv virtual environments. `requirements-lock*.txt` pin the exact versions. Their `-e file://` lines
point at this checkout's absolute path on the Harvard cluster; change them to your path.

| venv | Python | Used for | Lock file |
|---|---|---|---|
| `.venv` | 3.9 | robomimic (`train_adsrl.py`), plotting, most scripts | `requirements-lock.txt` |
| `.venv-pi0` | 3.11 | π0 on LIBERO | `requirements-lock-pi0.txt`, `scripts/pi0/install_venv_pi0.sh` |
| `.venv-pi05` | 3.11 | π0.5 on LIBERO | `requirements-lock-pi05.txt` |
| `.venv-furniture` | 3.8 | FurnitureBench | `requirements-lock-furniture.txt`, `scripts/furniture/install_venv_furniture.sh` |

```bash
uv venv .venv --python 3.9 && source .venv/bin/activate && uv pip install -r requirements-lock.txt
```

## Running

```bash
source .venv/bin/activate
pytest tests/                                   # CPU; some tests need the robomimic checkpoints
python train_adsrl.py --config-name=transport steer.mode=fixed steer.k=3 seed=1
python train_adsrl.py --config-name=transport steer.mode=adaptive steer.rho=0.5 steer.k_entropy_bias=detach
python train_adsrl.py --config-name=transport name=<same name> resume=true      # resume from checkpoint/latest.pt

source .venv-pi0/bin/activate
python train_adsrl_pi0.py --task_id 4 --steer.mode adaptive --steer.rho 0.5 --total_env_steps 1000000
```

The exact settings of every reported run are in the SLURM script and command recorded in its `exp_*.md`
document. Transport runs pack several seeds on one GPU with CUDA MPS (`scripts/slurm/exp3_wave1.sbatch`,
`scripts/slurm/exp13_dip.sbatch`).

## Where outputs go

robomimic runs write to `./logs/adsrl/<task>/<name>` (`log_dir=` changes it; in the original checkout `logs/adsrl`
is a symlink to scratch). LIBERO runs default to the original author's scratch space; set `--logdir_root`. The
plotting scripts read runs from that scratch path too: change `RUNS` in
`scripts/plots_seeds.py` and the defaults in `adsrl_pi0/__init__.py` (openpi and JAX cache paths). Each run
writes `eval_summary.csv` (one row per eval), `run_info.json` (config, git hash), checkpoints and, for
robomimic, per-chunk eval dumps in `eval_rollouts/`.

## Regenerating the report figures

```bash
source .venv/bin/activate
python scripts/plots.py --runs_root logs/adsrl   # main figures
python scripts/plots_seeds.py                    # three-seed figures (LIBERO and transport)
python scripts/plots_exp13.py                    # equal control strength, early dip, headroom
python scripts/plots_kchoice.py                  # which step adaptive k picks on transport
python scripts/pi0/plots_pi0.py                  # π0 LIBERO figures
```

Rollout videos are not in git; render them with `scripts/render_rollouts.py` and `scripts/pi0/render_libero.py`.
