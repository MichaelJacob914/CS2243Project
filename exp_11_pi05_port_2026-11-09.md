# Experiment: port steering to π0.5 and find LIBERO tasks with headroom
Status: Completed (Phase 0: port + base eval)

## Goal
Use the stronger π0.5 base policy (RL benefits from a good base) for adaptive-step steering. Phase 0: port the steering code to π0.5 without breaking the π0 setup, then measure plain π0.5 success on LIBERO-90 (and LIBERO-10) to pick tasks with base success around 30–70% for training.

## Setup
- Separate venv `.venv-pi05` with an upstream openpi that has π0.5 (the DSRL-π0 fork in `dsrl_pi0/openpi` has none), so `.venv-pi0` and running π0 jobs stay untouched.
- Checkpoint: openpi's public π0.5 LIBERO checkpoint (to confirm: name, training suites, action horizon).
- Port `adsrl_pi0/sampler.py` steering (re-noise at step k, same semantics as π0) to π0.5's denoising loop; tests mirror tests/test_pi0_sampler.py (k=0 equivalence, w = implied noise reproduces plain sampling, mixed-k batch).
- Base eval: plain π0.5, LIBERO-90 all 90 tasks × 20 episodes, plus LIBERO-10 tasks 4/6/8 × 50 for comparison with π0.
- Compute: install on CPU; tests + base eval ≈ 3–5 H100-hours. Kempner is at 14/15 GPUs from exp10, so GPU jobs may queue on kempner or go to gpu/gpu_h200 (olveczky_lab).
- Implementation: subagent, then Fable correctness review before any training launch.

### π0.5 facts (upstream openpi @ 215abfb, cloned to third_party/openpi_upstream)
- Config `pi05_libero`: `Pi0Config(pi05=True, action_horizon=10, discrete_state_input=False)`, action_dim 32 (7 real
  LIBERO dims, LiberoOutputs keeps [:7]), max_token_len 200, quantile normalization (`use_quantile_norm` for non-pi0).
- Checkpoint `gs://openpi-assets/checkpoints/pi05_libero` (public; fetched with gcsfs token='anon', no gsutil),
  cached at $OPENPI_DATA_HOME/openpi-assets/checkpoints/pi05_libero. Fine-tuned 30k steps from pi05_base on
  `physical-intelligence/libero` = LIBERO-Spatial/Object/Goal/10 (no LIBERO-90). Reported: 98.8/98.2/98.0/92.4 (avg 96.85).
- openpi's LIBERO eval replans every 5 steps (replan_steps=5 of the 10-step chunk), 224x224 resize-with-pad, same obs
  keys and 8-d state as π0 (state is not tokenized for pi05_libero since discrete_state_input=False).
- Time conditioning: π0 concatenates a sincos time embedding with each action token and mixes with an MLP, plus a
  continuous state token in the suffix. π0.5 has no state token in the suffix; the sincos embedding goes through
  time_mlp_in/out (swish) and conditions the action expert via adaRMSNorm (`adarms_cond=[None, cond]` to the LLM).
  `sample_actions(rng, obs, *, num_steps=10, noise)` is otherwise the same loop (prefix KV cache, 10 Euler steps,
  t: 1 → 0, x_{t+dt} = x_t + dt·v, same while_loop/stop rule), so steering semantics carry over unchanged.

### Code changes (π0 defaults unchanged)
- `adsrl_pi0/sampler.py`: one `_velocity` helper used by steered_sample_actions / plain_features / implied_noise_at;
  passes `adarms_cond` iff `embed_suffix` returns 4 values (upstream). Fork π0 path is the same ops as before.
  `MODELS = {pi0: (pi0_libero, s3://…/pi0_libero), pi05: (pi05_libero, gs://…/pi05_libero)}`, `SteeredPi0.load_model(name)`.
- `train_adsrl_pi0.py`, `scripts/pi0/base_eval.py`: `--model {pi0,pi05}` (default pi0); `--query_freq` default 20 (pi0) /
  5 (pi05), error if > horizon; horizon-dependent obs dims (x_T full, a_base) use 50 / 10. Run name prefix = model.
- `.venv-pi05`: `scripts/pi05/install_venv_pi05.sh` (+ overrides.txt). jaxrl2 installed without dsrl_pi0/requirements.txt
  (its jax 0.5.0 / orbax 0.11.1 / ml_dtypes 0.5.1 / tensorflow 2.19 pins conflict with upstream openpi's jax 0.5.3,
  orbax 0.11.13, ml-dtypes 0.4.1 override); jaxrl2's actual imports (distrax, tfp jax substrate, gym, matplotlib, wandb)
  installed instead.
- Tests: `tests/test_pi05_sampler.py` via `scripts/pi05/tests.sbatch`.

## Analysis
- The port is exact: k=0 matches upstream π0.5 sampling, the implied-noise identity holds for every k, mixed-k batches
  match per-k calls. π0 code path unchanged (identical failure values with the original sampler on A100).
- LIBERO-10 tasks 4 and 6 are saturated under π0.5 (no RL headroom); task 8 (moka pots) stays at 0.66.
- LIBERO-90 is out of distribution for pi05_libero; 10 tasks sit at 0.2–0.7 (20 eps each, so ±0.1 SE).
- Training implication: query_freq 5 means 4× more chunks per env step than π0's 20 → 4× the pi0 calls, buffer
  transitions and SAC updates (UTD 20 per chunk) per env step. Consider query_freq 10 (full chunk) or a lower
  multi_grad_step; discount_chunk = 0.999^query_freq changes accordingly. The x_T/a_base obs shrink to 320 / 70 dims.
